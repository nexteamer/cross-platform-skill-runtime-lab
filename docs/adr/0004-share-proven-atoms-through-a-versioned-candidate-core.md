# Share proven atoms through a versioned Candidate Core Package

Keep product-neutral atoms in a pre-1.0 Candidate Core Package with one versioned Control Envelope, and let each lab repository retain its own Product Adapter. The Candidate Core Package and short-essay application initially coexist as separate modules in the Compatibility Lab repository rather than creating a third repository. The Public Image Integration Lab consumes an immutable tagged/checksummed package revision and both products must pass the Conformance Suite after a shared change. This concentrates fixes without prematurely declaring a universal framework; copying the control code, publishing a stable Core, and introducing Copier are deferred.
