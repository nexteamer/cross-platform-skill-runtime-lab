# Prove the control model in a public Compatibility Lab first

Build a fresh, public short-essay Compatibility Lab in this directory before integrating with Public Image. The lab will use new Git history and only reviewed, non-sensitive material; the original repositories remain unchanged. The original form of this decision placed the later Public Image snapshot in a private repository. ADR-0003 supersedes that repository-visibility choice with a separately gated Public-Source Lab Repository while retaining the phase order and protected-asset boundary.
